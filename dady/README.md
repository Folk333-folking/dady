# DADY — барбершоп с онлайн-записью (Go + SQLite)

## Запуск
```
go mod tidy
ADMIN_PASSWORD=ваш_пароль go run .
```
Сайт: http://localhost:8080 · Админка: http://localhost:8080/admin.html
База `dady.db` создаётся сама, демо-услуги и мастера добавляются при первом запуске. Порт — переменная `PORT`.

## Что есть
Витрина, прайс, барберы, запись (услуга → мастер → дата → время → имя/телефон), «Мои записи» по телефону (отмена/перенос не позднее чем за 2 часа), админка (список по дате, смена статуса).
Время 10:00–21:00, шаг 30 мин. Защита от двойной записи: проверка пересечений на сервере под мьютексом.

## Чего нет (дальше по этапам)
Фото, галерея, отзывы, карта; настоящий вход клиента (сейчас — по телефону, без подтверждения); редактирование услуг/мастеров/графика и блокировок в админке; статистика; промокоды; SMS-напоминания (нужен внешний сервис). Мастера работают в общие часы.
